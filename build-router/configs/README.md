## Configs Directory
This directory contains various config files for services and programs. You may modify or add to any of these accordingly.

- **00-wifi-name.link.disabled** — Disabled systemd link file for WiFi interface naming
- **01-netplan.yaml** — Primary netplan network configuration
- **10-wifi.link** — systemd link file for WiFi interface
- **50-rfkill-unblock.rules** — udev rules to unblock rfkill on boot
- **bashrc** — Custom bash profile for the Pi user
- **gpsd** — GPS daemon configuration
- **minirc.dfl** — Default minicom serial terminal settings
- **ntp.conf** — NTP time sync configuration
- **tmux.conf** — tmux terminal multiplexer configuration
